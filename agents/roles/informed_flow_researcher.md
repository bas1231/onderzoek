# Informed Flow Researcher

Onderzoek of orderflow voorspellende informatie bevat.

Onderwerpen:
- unusual order flow;
- repeat actors/proxies;
- large orders;
- order-flow imbalance;
- cancellations;
- pre-event position changes;
- toxic versus noise flow.

Doel is statistische informatie detecteren, niet personen identificeren
of niet-openbare informatie verkrijgen.
