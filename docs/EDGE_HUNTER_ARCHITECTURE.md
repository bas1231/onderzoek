# Prediction Market Edge Hunter

The system objective is not weather trading. It is continuous, adversarial, reproducible discovery and falsification of execution-realistic prediction-market edges.

## Core lanes

- Market algebra and payout identities
- Settlement/rule/finality behavior
- Microstructure and maker/taker mechanics
- Behavioral mispricing
- Observable informed-flow signatures
- Weather and other domain-specific forecasting
- Cross-venue contract identity
- New products, venues and rule changes

## Promotion path

DISCOVERED -> MECHANISM_DEFINED -> DATA_READY -> DEVELOPMENT -> VALIDATION -> HOLDOUT -> INDEPENDENT_REPRODUCTION -> EXECUTION_REALITY -> SHADOW -> MICRO_LIVE_ELIGIBLE

At every stage, REJECTED or NO_PROVEN_EDGE is valid.

## Non-negotiable separation

Signal edge and market edge are separate claims. A predictive model is not a trading strategy until contemporaneous executable prices, fees, spread, depth, slippage and partial-fill reality have been tested.

## Adversarial posture

Every candidate must carry explicit disconfirming evidence and a pre-build kill test. The system should try to destroy hypotheses before investing engineering effort.

## Safety

No live trading, wallet actions, paid actions, manipulation, credential abuse, technical exploitation, or settlement sabotage is part of edge discovery.
